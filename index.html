登录 Cloudflare

使用 API Token 登录。Token 只保存在本机，不会上传到任何地方。

去哪里创建 Token？

打开 Cloudflare 控制台 → 右上角头像 → My Profile → API Tokens → Create Token → Create Custom Token，建议权限：

  • Account · Cloudflare Pages · Read
  • Account · Cloudflare Pages · Edit（要部署 Pages 才需要）
  • Account · Workers Scripts · Read
  • Account · Workers Scripts · Edit（要部署 Workers、绑 Worker 域名才需要）
  • Account · Workers KV Storage · Read
  • Account · Workers KV Storage · Edit（要用 KV 空间才需要）
  • Account · Cloudflare Tunnel · Read
  • Account · Cloudflare Tunnel · Edit（要用隧道才需要）
  • Account · Account Settings · Read
  • Zone · Zone · Read
  • Zone · DNS · Edit（要改 DNS 记录才需要）
  • Zone · Analytics · Read（要看用量才需要）

也可以用 Global API Key 登录，本应用只支持 API Token 方式。
